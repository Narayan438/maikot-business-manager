# Maikot Computer & Stationery – Purchase & Supplier Manager

Version 1 features:
- Dashboard
- Product master
- Supplier / wholesale shop master
- Purchase entry
- Automatic actual unit-cost calculation
- Selling-price based profit per unit
- Supplier price comparison

## Setup
1. Upload project files to a PHP-enabled hosting folder/subdomain.
2. Create/import the MySQL database using `database.sql`.
3. Edit `config/database.php` with the correct DB name, username and password.
4. Open `index.php`.
